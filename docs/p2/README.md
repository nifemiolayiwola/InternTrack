# InternTrack P2 - Analysis and High-Level Design

## PROJECT SUMMARY
  InternTrack is an web application internship tracker that helps students organize and track their internship applications. Students can add applications, update their status, save interview dates, upload documents and view their application progress. The goal of this project is to make it easier for students to keep track of their internship applications all in one place.


## MAIN FEATURES
1. Student registration and login
2. Add, edit, view, and delete internship applications
3. Update application statuses and view status history
4. Save interview dates and deadlines
5. View reminders inside the application
6. Search and filter applications
7. View dashboard statistics
8. Upload PDF resumes and cover letters
